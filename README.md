# Midjourney 电影提示词 Skill

把自然语言中的电影人物、角色定妆、场景和静帧想法，整理成适合 Midjourney 官网的提示词。当前版本：**1.1.0**。

默认交付一条可复制英文提示词、忠实中文和对应官网设置。用户说“先讨论”时，先讨论视觉方向，确定后再出词。

## 使用

主入口是 [SKILL.md](SKILL.md)，具体规则和示例在 `references/`。安装时保留整个目录，不要只复制主文件。Codex 的常用安装位置是 `~/.codex/skills/midjourney-film-prompts/`；已有同名个人版时，先保留原版并比较差异，不要直接覆盖。

调用示例：

```text
$midjourney-film-prompts
我要一张电影场景：清晨的废弃玻璃温室，野花长满走道，温柔而有重生的感觉。请给英文提示词、中文和官网设置。
```

也可以先讨论：

```text
$midjourney-film-prompts
先讨论，不出词。我想让两个人物在同一场景中出现，保持之前的外貌和服装，帮我梳理参考图与构图方案。
```

Skill 负责文字与设置建议，图片上传、参考绑定和提交生成由用户在 Midjourney 官网完成。

## 交付与工作方式

| 项目 | 行为 |
|---|---|
| 英文提示词 | 画面描述在前，适配模型的参数在后；可复制到官网 Imagine 输入框 |
| 忠实中文 | 对应英文中的主体、数量、动作、关系、光色与限制，不另外增加剧情 |
| 官网设置 | 说明哪些已写入提示词，哪些需手动设置或上传参考图 |
| 电影美学 | 按画面目标选风格，保留 Midjourney 的审美发挥；不统一强制 Raw、低 Stylize 或固定电影滤镜 |
| 人物与场景连续性 | 按需使用参考图、多人混串修复、换视角与局部编辑，不承诺身份或空间绝对一致 |
| 系列风格 | 沿用已确认的 Style Reference、Moodboard 或个性化来源及真实代码 |

普通出词直接使用附带资料，不自动联网检查版本和文档。只有用户明确要求查询或更新资料时才检索。

本包的官方资料基线是 **2026-10-23**，默认通用模型为 **V8.2**；这不表示它永远是最新版本。遇到未收录的型号或功能，不猜测参数。官方语法决定兼容性，电影表达顺序、具体风格词和候选参数值属于创作方法，并非官方规定的唯一模板。

## v1.1.0 的变化

- 移除常规出词中的自动联网核验和联网失败处理。

- 补充电影画幅整数写法、图中文字修复、Draft 构图探索和 Editor Layers 的按需说明。

- 保留原有提示词长度处理和隐私参数处理，没有增加字符硬上限或重复提醒。
